
### **修正後的欄位設計規格書 (Final Decile-Aware Version)**

#### **第一張：退休生活風格卡 (Retirement Lifestyle Card)**

* **定位**：**活躍退休期 (Active Retirement Phase / Go-Go Years)** 的現金流預測。
* **核心公式更新**：
* **關鍵修正**：
1. **時間自由乘數 (Time Freedom Multiplier)**：因退休後每週 7 天皆假日，休閒消費頻率增加，故信用卡支出需乘上 **1.1**。
2. **活躍期健康常數 (Active Health Constant)**：報告指出每年約 **$80,000** (月均 $6,700) 的剛性預防醫學支出（非健保、非長照）。



| 區塊         | 欄位名稱 (Field)        | 預設值/邏輯           | 新報告依據 (Evidence)                                                               |
| ------------ | ----------------------- | --------------------- | ----------------------------------------------------------------------------------- |
| **財務定位** | **財務身份 (Decile)**   | *自動偵測 (D1-D10)*   | **消費慣性**：依月薪定位。若為「享樂刷卡族」(刷卡佔比>70%)，替代率需求將突破 100%。 |
| **生存基底** | **真實月開銷基數**      | *信用卡平均  **1.1*** | **時間自由乘數**：報告證實退休後因閒暇時間釋放，變動消費(信用卡)會增加 10%。        |
|              | **生存替代率 (PR-ERR)** | *依階層連動*          | **階級分層**：D1 (100% 被迫) vs D10 (60% 資產釋放)。                                |
|              | **活躍健康維護**        | **$6,700 / 月**       | **剛性常數**：報告指出每年 $80,000 為預防醫學、牙齒、營養品的必要開銷（非長照）。   |
|              | **居住狀態**            | 自有 / 租屋 / 機構    | **居住紅利**：自有宅視為資產緩衝；租屋視為高通膨風險。                              |
|              | **家庭結構**            | 單身 / 雙人           | **單身懲罰**：若選單身且為中低所得，自動加成 15% 基礎開銷。                         |
| **活躍圓夢** | **活躍生活風格**        | L1 ~ L10 (年預算)     | **階層落差**：計算「期望生活 (L級)」與「原本階層 (D級)」的資金缺口。                |

#### **第二張：醫療財務防禦卡 (Medical Defense Card)**

* **定位**：**風險轉嫁 (Risk Transfer)** 與 **重大傷病儲備**。
* **區隔說明**：第一張卡的「健康維護」是**日常保養**（牙齒/維骨力）；這張卡是**救命錢**（癌症/手術）。

| 區塊         | 欄位名稱 (Field)   | 預設值/邏輯        | 新報告依據 (Evidence)                                                       |
| ------------ | ------------------ | ------------------ | --------------------------------------------------------------------------- |
| **防禦策略** | **醫療防禦等級**   | 基礎 / 品質 / 尊榮 | **階層連動**：D1-D3 預設「基礎型 (健保)」，D8-D10 預設「尊榮型 (全自費)」。 |
| **通膨設定** | **醫療專屬通膨**   | **3.5% - 4.5%**    | **J-Curve**：醫療通膨長期高於 CPI，需獨立設定。                             |
| **極端風險** | **重大傷病準備金** | $50萬 - $200萬     | **資產保護**：防止一次性大額支出擊穿退休金。                                |

#### **第三張：長照風險戰略卡 (LTC Strategy Card)**

* **定位**：**失能期 (No-Go Years)** 的照護對策。
* **關鍵修正**：引入**「混合照顧模式」**與**「外看隱形各項成本」**。

| 區塊         | 欄位名稱 (Field) | 預設值/邏輯        | 新報告依據 (Evidence)                                                           |
| ------------ | ---------------- | ------------------ | ------------------------------------------------------------------------------- |
| **啟動時機** | **預估失能年齡** | 80歲               | **不健康餘命**：平均約 8 年需人照顧。                                           |
| **戰略選擇** | **照顧模式配置** | 家人 / 外看 / 機構 | **隱藏成本**：報告揭露外籍看護除薪資外，另有食宿、健保等約 $5,000/月 隱形成本。 |
| **通膨設定** | **照護專屬通膨** | **3.0% - 5.0%**    | **人力通膨**：反映未來少子化導致的人力短缺成本（包默病）。                      |
| **補充包**   | **雜支與耗材**   | +$12,000           | **補漏**：機構費通常不含尿布、營養品與管灌配方。                                |
