這是一個非常明智的暫停。在進入程式碼生成之前，我們根據這四份深度報告，對欄位進行最後一次的**「現實檢核 (Reality Check)」**。

為了確保模型能模擬 **「真實現狀」** 而非只是理想數字，我發現原本的構想漏了 **兩個關鍵變數**：**「居住狀態」** 與 **「通膨的差異性」**。

以下是針對三張卡片的**最終欄位設計規格書**。請您檢視這是否符合您心中「模擬現實」的標準：

### 第一張：退休生活風格卡 (Lifestyle Card)

**設計邏輯：** 基於《預測退休開支》報告，退休支出不是一條平線，而是**微笑曲線 (Spending Smile)**。

| 區塊 | 欄位名稱 (Field) | 預設值/選項 | 設計理由 (Evidence-based) |
| --- | --- | --- | --- |
| **生存基底** | **真實月開銷基數** | *(自動帶入)* | **定錨效應**：報告指出退休前的消費慣性是預測最強指標。 |
|  | **居住狀態校正** | 自有 / 租屋 / 養老宅 | **關鍵修正**：若是租屋，需額外承擔「房租通膨」風險；若是自有，需承擔「修繕稅費」。此變數影響巨大。 |
| **活躍圓夢** | **旅遊與娛樂強度** | 國內漫遊 / 亞洲短程 / 環遊世界 | **微笑曲線左端**：對應 Go-Go Years 的高支出。此欄位直接影響退休前 10 年的預算加權。 |
|  | **預估生活通膨率** | 2.0% ~ 2.5% | **購買力風險**：一般物價指數 (CPI)。 |
| **健康投資** | **預防醫學預算** | $3,000 ~ $5,000 | **主動防禦**：報告強調「前端投資」可縮短後端不健康餘命。 |

### 第二張：醫療財務防禦卡 (Medical Defense Card)

**設計邏輯：** 基於《退休醫療各階段分析》，對抗 **「醫療通膨」** 與 **「雙峰支出」**。

| 區塊 | 欄位名稱 (Field) | 預設值/選項 | 設計理由 (Evidence-based) |
| --- | --- | --- | --- |
| **通膨設定** | **醫療專屬通膨率** | **3.5% ~ 4.5%** | **關鍵修正**：報告證實醫療通膨遠高於 CPI。若用一般通膨算，20 年後會嚴重低估。 |
| **日常維修** | **自費醫療等級** | 健保型 / 品質型 / 尊榮型 | **平準化攤提**：將植牙(65歲)、白內障(70歲)、慢性病(75歲+) 的費用「月費化」，方便試算。 |
| **風險緩衝** | **重大傷病預備金** | $50萬 / $100萬 / $200萬 | **極端值防禦**：針對癌症標靶、免疫療法等健保不給付的一次性重擊。 |

### 第三張：長照風險戰略卡 (LTC Strategy Card)

**設計邏輯：** 基於《長照比例估算》與《自費比較》，揭露 **「市場失靈」** 與 **「隱藏成本」**。

| 區塊 | 欄位名稱 (Field) | 預設值/選項 | 設計理由 (Evidence-based) |
| --- | --- | --- | --- |
| **啟動時機** | **預估失能年齡** | 80歲 (依不健康餘命) | 決定這筆大額支出何時爆發。 |
| **戰略選擇** | **照顧模式配置** | 家人 / 外看 / 混合 / 機構 | **核心欄位**：會連動下方的「隱藏成本」與「警示訊息」。 |
|  | **(連動) 統計佔比** | *(自動顯示 %)* | **從眾參考**：讓用戶知道此選項是主流還是小眾 (例如純外看佔 9.7%)。 |
| **殘酷現實** | **照護專屬通膨率** | **3.0% ~ 5.0%** | **包默病 (Cost Disease)**：人力服務的薪資漲幅通常高於物價。長照是高度人力密集的產業。 |
|  | **隱藏雜支預估** | +$12,000 (機構耗材) | **補破網**：機構費不含尿布營養品；家人照顧不含薪資損失。此欄位專門補漏。 |

### 最終檢核點 (Final Check)

這套設計與舊版最大的差異在於：

1. **居住風險**：加入了「房租」變數。
2. **差別通膨**：生活(2%)、醫療(4%)、長照(5%) 分開設定。這非常專業且殘酷，因為越老花的錢通膨越高。
3. **模式連動**：長照模式的選擇會直接改變背後的計算邏輯（而不只是金額不同）。

**如果這三個修正方向（居住、差別通膨、模式連動）您都認可，我就開始依照這個架構生成三張卡片的程式碼。**
